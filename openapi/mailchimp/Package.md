|                               | Version          |
|-------------------------------|------------------|

| API Version                   | 3.0.52           |

### Package Overview
The `mailchimp` is a [Ballerina](https://ballerina.io/) connector for *Mailchimp*.
This package provides the capability to easily access *Mailchimp*.
